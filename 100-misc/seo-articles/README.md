## Suggested order (about 6 weeks)

1. **Week 1:** Create the Blogger blog and publish **03**. Publish **01** on Medium.
2. **Week 2:** Publish **04** on WordPress.com. Post Quora **05e** (no link) and **05a**.
3. **Week 3:** Publish **02** on LinkedIn. Post Quora **05b**. Start commenting in r/Sikh (no links).
4. **Week 4:** Send the **07** pitch to 5–10 qualified outlets. Post Quora **05c**. Start **08** pins/posts weekly.
5. **Week 5–6:** Post **06** on Reddit once the account has real history. Post Quora **05d**. Follow up on pitches once.
6. **Ongoing:** Add 2–3 more posts to the Blogger and WordPress blogs over time (a one-post blog carries little weight). Write new articles for other site sections (Sikh legends, Sehaj Path, Matrimonials, Purpose of Life).

## Before posting each piece

- [ ] Re-read for accuracy and adjust the voice to sound like you. Add a personal detail or photo.
- [ ] Click every sikhsinindia.com link in the preview to confirm it opens.
- [ ] Don't paste the same text on two platforms.
- [ ] Keep the disclosure line ("I help run SikhsInIndia.com") where it's given.
- [ ] After it's live, add the URL above and check its link type (right-click → Inspect → look for `rel`).

- **Google Analytics** (tag `G-LHNTFNW14H` is on the pages): *Acquisition → Traffic acquisition*, filtered by session source (medium.com, quora.com, linkedin.com, reddit.com…).
